# Plantilla Barbería / Peluquería

Plantilla web profesional para barberías.
Diseño moderno, adaptable y fácil de personalizar.

## 📁 Estructura del proyecto
- /static/css → estilos
- /static/img → imágenes
- index.html → estructura principal

## 🎨 Cambiar colores
Edita las variables en el archivo CSS:

:root {
  --color-principal
  --color-oscuro
  --color-claro
}

## 📲 WhatsApp
Cambia el número en el botón "Reservar cita".

## 🖼️ Galería
Reemplaza las imágenes en /static/img
