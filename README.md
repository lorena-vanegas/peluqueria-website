# Hair Salon Website Template 💇‍♀️

## 📌 Description

A modern and responsive hair salon website template built with HTML, CSS, and JavaScript.

This project was created as a reusable template that can be customized for hair salons, beauty studios, or other small businesses looking for a professional online presence.

## 🚀 Features

- Responsive design for desktop, tablet, and mobile devices
- Modern and clean user interface
- Hero section
- Services section
- Gallery
- About section
- Contact section
- Easy to customize

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

- `template/` → HTML files
- `static/` → CSS files and images
- `script.js` → Website interactivity
